The seven phase model

Every phase has a gate. WZD keeps the work narrow until the business has the facts needed to move forward.

1

Intake

Capture the idea, constraints, budget, timeline, and income goal.

2

Idea

Find a real demand signal before writing more plans.

3

Model

Define price, cost, margin, and breakeven customers.

4

GTM

Choose one customer, one channel, and the first targets.

5

Build

Create the smallest sellable offer and only the assets needed to sell it.

6

Revenue

Drive outreach, replies, calls, offers, sales, and cash collected.

7

Review

Review facts, lock decisions, and pick the next focused move.

Run it in minutes

Clone the repo, install dependencies, add your OpenAI API key, and start the agent.

1 git clone https://github.com/wzdlabs/wzdsh.git
2 cd wzdsh && bun install
3 export OPENAI_API_KEY="your_key"
4 bun run start
